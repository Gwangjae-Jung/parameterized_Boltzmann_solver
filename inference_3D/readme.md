# 3D 추론 및 벤치마크 모듈 (`inference_3D`)

본 디렉터리는 학습 완료된 3차원 볼츠만 신경 연산자 모델들의 추론 성능, 시계열 롤아웃(Rollout) 오차, 연산 속도 및 GPU 메모리 사용량을 종합적으로 평가하고 시각화하는 환경입니다.

3차원 속도 공간($v = (v_1, v_2, v_3) \in \mathbb{R}^3$)에서는 격자 해상도 $N^3$에 따른 메모리와 연산량이 급격히 증가하므로, 모델의 압축률과 연산 효율성이 핵심 지표로 다루어집니다.

---

## 1. 주요 노트북 및 스크립트 구성

- **`inference.ipynb`**:
  - **3D 핵심 평가 노트북**: 초기 3D 분포 $f_0$로부터 최종 시간까지 순차 추론을 수행하여 참값 대비 상대 $L_2$ 오차율을 산출합니다.
  - 3차원 슬라이스 단면 및 적분 모멘트(질량, 운동량 벡터, 운동 온도)의 보존 오차를 정량 분석합니다.
- **`inference__speed.ipynb`**:
  - 3차원 고차원 텐서에 대한 모델별 연산 시간 및 초당 프레임 수(FPS)를 측정합니다.
- **`inference__peak_memory__*.ipynb`**:
  - 3D 격자에서 각 아키텍처가 점유하는 GPU VRAM 피크치를 측정하여 메모리 절감 효과를 입증합니다.
- **`loader.py`**:
  - 3D 체크포인트 데이터를 로드하기 위한 유틸리티 모듈입니다.
- **`dataset.py` & `plot.py`**:
  - 3D 데이터 파이프라인 및 시각화 도구 모음입니다.
- **`ood_test_dataset/`**:
  - 3차원 Out-of-Distribution 테스트 궤적 데이터를 저장하는 디렉터리입니다.

---

## 2. 사용 방법

1. Jupyter Notebook 환경에서 `inference.ipynb`를 실행합니다.
2. 설정 셀에서 평가할 모델 사양을 선택하고 순차적으로 실행합니다:
   ```python
   DIMENSION     = 3
   list_max_freq = [6, 8, 10]
   max_freq      = list_max_freq[1] # 예: max_freq=8
   seed          = 0
   res_v         = 64               # 3D 격자 해상도 (64^3)
   ```
