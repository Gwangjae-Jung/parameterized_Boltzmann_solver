# 데이터 생성 유틸리티 (`generate_data/utils`)

본 디렉터리는 볼츠만 방정식 수치해 데이터셋 생성에 필요한 보조 유틸리티 함수와 설정 관리 클래스를 포함하고 있습니다.

---

## 1. 모듈 구성

- **`config_loader.py` (`ConfigLoader`)**:
  - YAML 형식의 설정 파일을 파싱하고 검증하는 클래스입니다.
  - 연산 정밀도(`dtype`), 연산 장치(`device`), 격자 크기(`res_v`, `max_v`), 시간 파라미터(`delta_t`, `max_t`) 및 저장소 경로(`storage`)를 속성으로 제공합니다.
  - 저장 경로가 상대 경로이거나 절대 경로일 때 프로젝트 루트(`_ROOT`)를 기준으로 안전하게 매핑되도록 처리합니다.
- **`sampling.py`**:
  - Bi-Maxwellian 분포를 구성하기 위해 두 맥스웰 분포의 평균 속도와 온도를 무작위로 섭동(perturbation)시키는 샘플링 함수를 제공합니다.
- **`normalizer.py`**:
  - 생성된 수치 분포 함수의 총 질량이 보존되도록 속도 공간 격자 부피($\Delta V$)를 고려하여 밀도를 단위 질량으로 정규화하는 기능을 수행합니다.
- **`__init__.py`**:
  - 상기 모듈들의 주요 클래스 및 함수들을 패키지 수준에서 즉시 임포트할 수 있도록 노출합니다.
